# Renewal engine. Pinned exactly, not floored (>=), for one specific reason:
# models/real_latest.joblib is a PICKLE of a fitted scikit-learn pipeline, and
# scikit-learn gives no cross-version pickle-compatibility guarantee. With
# "scikit-learn>=1.3" a fresh container build would install a much newer
# sklearn and load a model trained on 1.3.2 -- best case an
# InconsistentVersionWarning nobody reads, worst case silently different
# predictions or an outright failure at load. The ML stack below is the
# version set the shipped model was fitted with; changing any of it means
# retraining and re-publishing, not just editing this file.
